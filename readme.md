В файле main.py размещён код, который запускает программу. 
Это тестовый вызов функций get_mask_card_number и get_mask_account, чтобы проверить, как они работают, или пример 
использования этих функций. Таким образом, main.py служит точкой входа в программу, где ты можешь протестировать и 
продемонстрировать функциональность проекта.

Этот код импортирует функции из модуля masks и использует их для маскировки номеров карты и счета, затем выводит 
результаты на экран.
