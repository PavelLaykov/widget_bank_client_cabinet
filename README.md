# =========Banking widget==========
# Виджет банковских операций

## Основная цель программы
### Банк работает со счетами клиентов, постоянно расширяя спектр услуг.
### IT-отдел банка разрабатывает Banking widget - это backend, который готовит данные для отображения в widget, в личном кабинете клиента крупного банка.
### Это виджет, который показывает несколько последних успешных банковских операций клиента. 

## Реализованы функции:
    1. Функция маскировки номера банковской карты 
    2. Функция маскировки номера банковского счета
    3. Сортировка по статусу сделок и дате их совершения
    4. Функция для поиска в списке словарей операций по заданной строке — описанию с использованием библиотеки 
    re.


## Widget
    * Этот модуль будет содержать функции для работы с новыми возможностями приложения.
    * В модуле обрабатывается информацию как о картах, так и о счетах, анализирует транзакции клиентов.

## -------------Установка и использование-------------

### **Требования (Requirements):**

    1. **Python** версии 3.14.3
    2. **Poetry** версия 2.3.2
    3. Смотрите файл `pyproject.toml` для получения информации о версиях зависимостях проекта.

### **Установка:**

## Для использования проекта необходимо:

    1. Установить [PyCharm](https://www.jetbrains.com/ru-ru/pycharm/download/?section=windows).
    2. Установить интерпретатор [Python](https://www.python.org/downloads/).
    3. Установить в PyCharm poetry.

    ```
    # В PowerShell

    Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing.Content | python -
    ```

    Или через curl (если установлен).

    ```
    curl -sSL https://install.python-poetry.org | python -
    ```

    4. **Клонируйте проект** из этого репозитория, используя в PyCharm (в командной строке терминала) команду:

    git clone https://github.com/git@github.com:PavelLaykov/homework_13_2.git

    5. **Инициализируйте виртуальное окружение** командой:

    python -m venv <название_окружения>

    *Например:*

    python -m venv venv

    Однако важно убедиться, что у вас корректно настроен путь к Python в системной переменной `PATH`, чтобы команда работала без ошибок. О том, как добавить Python в PATH в Windows 11, смотри [здесь](https://ip-calculator.ru/blog/windows-11/how-to-add-python-to-path-on-windows-11-2/).
    1. **Активируйте окружение** с помощью команды:
    *   на macOS и Linux:

    source venv/bin/activate

    *   на Windows:

    venv\Scripts\activate

    * Или используйте `poetry shell` для активации виртуального окружения (доступно только при 
    установленном плагине `poetry-plugin-shell`).*
    2. **Установите все зависимости проекта** (указанные в файле `requirements.txt`) командой:

    pip install -r requirements.txt

    Также можно установить линтеры на выбор, используя Poetry с помощью команды:

    poetry add --group lint <линтер>

    Замените <линтер> на имя нужного линтера, например `flake8` или `mypy`, и они будут указаны в pyproject.toml. 
    Если же использовать команду:

    poetry add <линтер>

    Тогда линтеры будут установлены для всего PyCharm

    3. Открыть PyCharm и установить пакеты, указанные в pyproject.toml.

## Файл .src/generators.py.

### Итератор def filter_by_currency

    Функция выполняет фильтрацию транзакций по выбранному типу валюты (USD, RUB д.т.).

### Генератор def transaction_descriptions

    Функция-генератор принимает список словарей и возвращает описание проведенной операции.

### Генератор card_number_generator
    Функция генерирует номер карты в заданном диапазоне.

## Файл .src/decorators.py.
    В файле decorators созданы функции-декораторы для записи результата в консоль или в указанный файл, если таковой задан.

## Файл .src/mylog.txt.
    Лог-файл для вывода данных о выполнении функций.

    Созданы логеры для модулей masks и utils в папке logs в корне проекта. 
    Файлы логов имеют расширение .log. Формат записи лога в файл включает 
    метку времени, название модуля, уровень серьезности и сообщение, 
    описывающее событие или ошибку, которые произошли.
    Лог перезаписывается при каждом запуске приложения.

## Файл transactions.csv
    Файл содержит данные об операциях в формате .csv.

## Файл transactions_excel.xlsx
    Файл содержит данные об операциях в формате .xlsx.

## Файл .src/financial_operations.py

    В файле financial_operations созданы функции:

    read_csv_transactions()
    Функция считывания CSV файла, возвращает список словарей,
    :param filename_csv: передаётся файл CSV
    :return: список словарей.

    read_excel_transactions()
    Функция считывания Excel файла, возвращает список словарей,
    :param filename_excel: Excel файл
    :return: список словарей операций из файла Excel

## Файл .src/banks_operations.py

    В файле banks_operations созданы функции:

    search_operations()
    Функция для поиска в списке словаре определенной операции по столбцу "description"
    :param operations: список словарей с операциями
    :param search: ключевые слова для поиска
    :return: список словарей с результатами поиска

    banking_operations()
    Функция для создания словаря с типом банковской операции по входным данным,
    где ключ = названия категорий, а значение = количество операций
    :param data_operations: список словарей с данными о банковских операциях
    :param categories: список категорий операций
    :return: словарь (ключ = названия категорий, значение = количество операций)
